# Language File Standards

Read this before changing files in `frontend/src/lang/`, along with ancestor `AGENTS.md` files.

## Translations

- Keep JSON valid and formatted with the repository formatter.
- Preserve stable translation keys unless every use site is updated.
- Use concise, user-facing copy. Do not add developer notes or implementation explanations to translation strings.
- When adding a UI string, check whether an existing key already matches the concept before creating a new one.
