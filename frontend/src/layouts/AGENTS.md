# Layout Standards

Read this before changing files in `frontend/src/layouts/`, along with ancestor `AGENTS.md` files.

## Scope

- Layouts should provide app shell structure, shared navigation/footer behavior, and route outlets.
- Keep page-specific fetching, tab playback behavior, and form workflows in `src/pages/` or dedicated components.
- Preserve responsive behavior and avoid nesting broad page sections inside decorative card wrappers.
